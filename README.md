# 🧠 DocuMind AI

An AI-powered NotebookLLM that allows users to upload PDFs and ask questions based on document content.

## 🚀 Features
- Upload multiple PDFs
- Extract and chunk text
- Semantic search using FAISS
- AI-powered Q&A (Groq LLM)
- Source citation (page + file)

## 🛠️ Tech Stack
- Python
- Streamlit
- FAISS
- Sentence Transformers
- Groq API

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
